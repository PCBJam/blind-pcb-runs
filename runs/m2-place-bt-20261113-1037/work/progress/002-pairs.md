# 002 – differential pairs (scripted, not autorouted)
Parts placed (all on top, all next to the PCIe socket except R2 at the M.2 edge), then all 18 high-speed
nets generated by a script (/tmp generator, applied with `bt apply --checked`):
B.Cu horizontal from the M.2 fingers -> diagonal via pair -> F.Cu vertical to the socket.
The via pair sits on the 45° mirror axis of the turn, so the turn *and* the P/N swap cost zero skew
(every pair: P length == N length, `bt length`). RX pairs and REFCLK drop back to B.Cu just above their
bottom-side socket pads. One GND return via per transition, one GND via per M.2/PCIe ground pin.
First probe found 5 clashes from one careless GND via under REFCLK; removed it, all clear.
A first sideband attempt (GND via for M.2 pin 51 at x=109.95) sat on the PWRGD/CLKREQ# finger exits;
moved that via east, turned R2 vertical, and re-generated.
