# 002 – differential pairs
All 9 pairs (8 PCIe data + REFCLK) generated by scripts/gen_pairs.py and written with `bt apply --checked`.

Topology: B.Cu from the M.2 fingers (short horizontal, common 45° run, horizontal), then a
mirrored via pair at each corner (N via up-left, P via down-right on the 45° axis) that turns the
pair 90° **and** swaps P/N, then straight down on F.Cu to J1. OUT pairs end on J1's F.Cu pads;
IN pairs and REFCLK drop back to B.Cu through a second via pair just above their pads.
Every crossing is a B.Cu horizontal under an F.Cu vertical, with both GND planes in between.

Result: probe all clear, every pair has 0.000 mm intra-pair skew by construction
(lengths 34.7–40.1 mm), vias 0.5/0.25 through F↔B so no stubs. Two GND return vias sit at each corner.
