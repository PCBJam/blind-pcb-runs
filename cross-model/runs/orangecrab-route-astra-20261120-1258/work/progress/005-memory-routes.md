# Memory routing trial

A 115-second batch routed 33 of the 51 requested DDR, clock, and USB nets. KiCad found 256 open connections on this candidate and no new copper-clearance errors. I kept it as the starting point for a geometry-based routing pass. A separate full-board Specctra trial counted hundreds of fixed-object clearance problems that KiCad could not reproduce, so its completion count alone would be insufficient to select a layout.
