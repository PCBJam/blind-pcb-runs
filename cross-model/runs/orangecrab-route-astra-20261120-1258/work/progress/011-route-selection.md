# Selecting compatible paths

I collected complete per-net alternatives from several routing orders and selected a compatible set using geometric clearance and hole-spacing checks. The first selection left three signal nets open. Shortening unused through-via barrels under the BGAs opened paths for two of them. This trial uses stacked adjacent-layer laser vias and core vias. KiCad’s refill left the ADC mux-select net and a ground island open at this checkpoint. I also kept a separate selection that gives the physically coupled memory strobes priority.
