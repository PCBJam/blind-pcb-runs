# Coupled memory clock and both strobes

A fresh memory-only trial cleared the previous data and command routes around the protected clock and UDQS. I routed LDQS as a pair, then restored signals in a corridor between the two packages. In this trial the LDQS track-length difference dropped from 8.67 mm to 0.43 mm and CAS# dropped from 34.72 mm to 14.01 mm. Some memory connections still needed alternative paths. The north-bank trials also showed that a complete signal from one routing order can be reused when it clears the signals chosen from another.
