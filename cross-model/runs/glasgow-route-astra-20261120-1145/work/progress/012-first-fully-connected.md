# First fully connected board

The last remaining connection was from an FPGA ball to R22 on the LED row. Enlarging the fine-grid search window to include both ends let it close after two nearby bus nets were rerouted. KiCad's connectivity check counted zero open connections after refill. The minimum signal width in this accepted pass was 0.15 mm. A separate 0.13 mm escape trial was discarded. This checkpoint precedes the final clock, thermal and dangling-copper review.
